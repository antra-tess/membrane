- `OpenAIResponsesAPIAdapter` now reads `usage.input_tokens_details.cache_write_tokens` into `usage.cacheCreationTokens`, so a prompt-cache write on OpenAI's Responses API leaves `inputTokens` under the cache-inclusive normalization and is priced on its own: every OpenAI row carries `cacheWritePerMillion` — 1.25× input from GPT-5.6 on, the guide's rate for the 30-minute cache, and the input rate on earlier models, which charge nothing extra. Before, the field was not read, so a write was counted and priced as ordinary input and the GPT-5.6+ premium was missing from `estimatedCost`.
