- A Bedrock stream frame of AWS EventStream's `error` message type (`:message-type` `error`, with `:error-code` and `:error-message`) now fails the stream as that error: its code is typed as a stream exception of the same name is (a `ThrottlingException` is a 429 `rate_limit`, an unknown code a retryable `server` failure), and its message is read as the provider's. Before, the frame was skipped, and the stream ended as "Bedrock returned empty response".
