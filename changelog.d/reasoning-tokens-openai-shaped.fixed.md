- The four OpenAI-shaped adapters — `OpenAIAdapter`, `OpenAIResponsesAPIAdapter`, `OpenRouterAdapter`, `OpenAICompatibleAdapter` — read the reasoning-token count the API reports (`usage.completion_tokens_details.reasoning_tokens`; `output_tokens_details.reasoning_tokens` on the Responses API) into `usage.thinkingTokens`, on a whole response and on a stream's usage frame. The count is inside `completion_tokens` / `output_tokens`, which is what `thinkingTokens` means ("already folded into `outputTokens`"), so totals and costs are unchanged; what changes is that a reasoning model's thinking is now visible in the usage report, as it has been for Gemini (`thoughtsTokenCount`) since that adapter set the field. Before, only the Gemini adapter set `thinkingTokens`; the OpenAI adapters declared the field in their usage types and never read it (#277).
