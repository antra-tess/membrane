- Models priced by prompt length are now billed at their long-prompt rates when a request's prompt — fresh input, cache writes and cache reads together — is longer than the provider's threshold: Claude Haiku 5.5 over 100k tokens, gpt-5.5 over 272k, Gemini 3.1 Pro and 2.5 Pro over 200k. `ModelPricing.longPrompt` carries the threshold and the rates that change; a rate it leaves unset keeps the row's base rate. Before, every prompt was priced at the short-prompt rate, which the table's own comments said under-priced a long one. Each abandoned attempt (a refusal that was retried) is now priced as the request it was, from the caller's model and the model that served it, and `discardedAttempts.estimatedCost` is their sum, present only while every attempt has one; before, the attempts' token totals were priced as one request at the requested model's rates, which could cross a tier none of them did. `pricingFor` returns a copy whose `longPrompt` is the caller's own.
