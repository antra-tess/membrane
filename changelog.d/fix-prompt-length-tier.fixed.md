- Models priced by prompt length are now billed at their long-prompt rates when a request's prompt — fresh input, cache writes and cache reads together — is longer than the provider's threshold: Claude Haiku 5.5 over 100k tokens; gpt-6-astra, gpt-5.6-sol, gpt-5.6-terra, gpt-5.6-luna, gpt-5.5 and gpt-5.4 over 272k (2× input, 2× cached input, 1.5× output, from OpenAI's pricing page); Gemini 3.1 Pro and 2.5 Pro over 200k. `ModelPricing.longPrompt` carries the threshold and the rates that change; a rate it leaves unset keeps the row's base rate. Before, every prompt was priced at the short-prompt rate, which the table's own comments said under-priced a long one. Each abandoned attempt (a refusal that was retried) is now priced as the request it was, from the caller's model and the model that served it, and `discardedAttempts.estimatedCost` is their sum, present only while every attempt has one; before, the attempts' token totals were priced as one request at the requested model's rates, which could cross a tier none of them did. `pricingFor` returns a copy whose `longPrompt` is the caller's own. An abandoned attempt whose provider left a usage count unreported carries no cost, so the attempts' sum has none; before, its defaulted zeros were priced. `promptTokens`, `ratesFor`, `addCostBreakdowns` and the `LongPromptPricing` type are exported.
