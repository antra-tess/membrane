- **Callers with their own `ModelRegistry` rows for OpenAI models:** a row without `cacheWritePerMillion` now leaves cache writes unpriced (before, the written tokens were counted and priced as input), and Membrane warns once per model when that happens. **Migration:** add `cacheWritePerMillion` to each OpenAI row — the input rate for GPT-5.5 and earlier (they charge nothing extra), 1.25× input from GPT-5.6 on — and, for GPT-5.6+ rows, `cacheWrite1hPerMillion` at 2.5× input for the Responses API's 12-hour writes. **Unchanged:** rows for other providers; the built-in table, which carries the rates; agent-framework and connectome-host, which pass no registry and so cope at any version.
