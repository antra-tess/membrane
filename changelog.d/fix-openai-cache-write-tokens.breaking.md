- **Callers with their own `ModelRegistry` rows for OpenAI models:** a row without `cacheWritePerMillion` now leaves OpenAI cache writes unpriced (before, the written tokens were counted and priced as input), and Membrane warns once per model when a cache write — from any provider — meets a row without that rate, on the turn path and on the per-round path of streams and tool loops alike. **Migration:** add `cacheWritePerMillion` to each OpenAI row: the input rate where OpenAI's page lists no write price (GPT-5.5 and earlier, `gpt-6-astra-law`), 1.25× input where it does (GPT-5.6, GPT-6), and on those rows `cacheWrite1hPerMillion` at 2.5× input for the Responses API's 12-hour writes. A row without `cacheWrite1hPerMillion` prices long-TTL writes at the short rate, as 0.10.4's Anthropic rows do. **Unchanged:** what a row without a write rate prices (nothing, by design — only the warning is new); the built-in table, which carries the rates; agent-framework and connectome-host, which pass no registry and so cope at any version.
