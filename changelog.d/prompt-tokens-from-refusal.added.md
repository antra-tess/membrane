- `MembraneError.promptTokens`: for a `context_length` error, the request's input token count where the provider's refusal states one, as a number only. Anthropic states it in "prompt is too long: N tokens > M maximum" and "input length and `max_tokens` exceed context limit: N + K > M", and Gemini in "The input token count (N) exceeds …"; OpenRouter passes on its upstream provider's. OpenAI's, the Responses API's and Bedrock's refusals state none, and leave it unset. From a provider's body, it's read from the body's own message fields, as the error's type is, never from a part that can echo the request. `ErrorInfo` carries it, so copies made with `toErrorInfo` keep it.
