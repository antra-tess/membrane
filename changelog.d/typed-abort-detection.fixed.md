- Abort detection is typed: only `name === 'AbortError'`, a `DOMException` AbortError, or a membrane `abort` error is reported as a cancellation. An error whose message merely contained "abort" — a host tool failing with "...aborted...", a provider mentioning idle-connection aborts — used to resolve the whole turn as `AbortedResponse{reason:'user'}`, destroying the real error and telling the caller the human cancelled; it now throws with its classification and raw request intact.
