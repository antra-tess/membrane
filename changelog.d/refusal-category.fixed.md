- **A refusal re-issue's `RetryingEvent.category` now carries the refused attempt's category through `AnthropicAdapter`.** Membrane read the category from `raw.response.stop_details` on the adapter's response, a shape no built-in adapter's raw response has: `AnthropicAdapter`'s raw carries `stop_details` at its top level. So the event never had a category for a real Anthropic refusal. The adapter now reports it as a new optional field, `ProviderResponse.refusalCategory`: Anthropic's `stop_details.category`, such as `'cyber'`, set on `stream()` and `complete()` when the response stopped with `refusal` and the category is a non-empty string. Membrane reads that field for the event. No other built-in adapter sets it, so their retrying events still have no category. A custom adapter supplies the field to have its category announced, and a decorator that rebuilds the provider's response carries it.
