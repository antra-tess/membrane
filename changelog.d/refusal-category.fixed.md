- **A refusal re-issue's `RetryingEvent.category` now carries the refused attempt's category through `AnthropicAdapter`.** Membrane read the category from `raw.response.stop_details` on the adapter's response, a shape no built-in adapter's raw response has: `AnthropicAdapter`'s raw carries `stop_details` at its top level. So the event never had a category for a real Anthropic refusal. The adapter now reports it in the new `ProviderResponse.refusalCategory` (under Added): Anthropic's `stop_details.category`, such as `'cyber'`, set on `stream()` and `complete()` when the provider stopped with `refusal` and the category is a non-empty string. Membrane reads that field for the event, and no longer reads the adapter's raw response for it. A custom adapter whose raw response carried the category at `response.stop_details`, the one shape that was read, sets `refusalCategory` to keep it on the event. No other built-in adapter's stream sets the field, so their retrying events still have no category.
