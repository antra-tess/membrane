- `OpenAIResponsesAPIAdapter` no longer counts a `keepalive` or `ping` event as progress. Such an event shows that the connection is up, not that the model is making progress. Before, frequent keepalive or ping events could keep a configured `progressTimeoutMs` from running out. Now such an event doesn't renew that timeout. While a model reasons, it may send only such events for a long time. If that time can be longer than your `progressTimeoutMs`, raise that value. `onProgress` is no longer called for such an event, also when no timeout is set.
