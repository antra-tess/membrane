- A Bedrock stream `error` event is read as the error's body, as the Anthropic adapter reads the same event from Anthropic's API: its own code, message and stated wait count. An `overloaded_error` event saying `retry_after_ms: 17000` now waits 17 s, where its wait was dropped. Before, membrane's rendering of the event was read as the provider's message, so a wait the event echoed outside any message could be taken for the provider's. A stream exception with its own message passes `{ message }` as the body, so that message is read without membrane's `Bedrock stream error (…): ` prefix. The error's message is unchanged.
