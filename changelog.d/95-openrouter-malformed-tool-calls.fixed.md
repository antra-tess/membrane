- OpenRouter: a malformed `tool_calls` entry in a complete response no longer fails the whole response (antra-tess/membrane#95). Before, `tool_calls: [{}]` threw "Cannot read properties of undefined (reading 'name')" and the text and usage were lost. Now an entry without a string `function.name` is skipped, with one warning per response that does not log provider content, and the rest of the message is kept. Well-formed calls are unchanged. The stream path already skipped such entries.
